macOS Tahoe ने Launchpad हटा दिया है, नया इंटरफ़ेस उपयोग में कठिन है और आपके Bio GPU का पूरा लाभ नहीं उठाता। Apple, कम से कम वापस जाने का विकल्प दें। तब तक, यह है LaunchOne।

### LaunchOne क्या प्रदान करता है
- ✅ **पुराने सिस्टम Launchpad से एक-क्लिक आयात** — आपके नेटिव Launchpad SQLite डेटाबेस (`/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db`) को सीधे पढ़कर मौजूदा फोल्डर, ऐप पोजिशन और लेआउट को पुनर्स्थापित करता है
- ✅ **क्लासिक Launchpad अनुभव** — प्रिय मूल इंटरफ़ेस जैसा ही
- ✅ **बहुभाषी समर्थन** — अंग्रेज़ी, चीनी, जापानी, फ़्रेंच और स्पेनिश
- ✅ **आइकन लेबल छुपाएँ** — जब ऐप नाम आवश्यक न हों तो मिनिमल व्यू
- ✅ **कस्टम आइकन आकार** — अपनी पसंद के अनुसार समायोजित करें
- ✅ **स्मार्ट फोल्डर प्रबंधन** — पहले की तरह फोल्डर बनाएं और व्यवस्थित करें
- ✅ **इंस्टेंट सर्च और कीबोर्ड नेविगेशन** — ऐप्स जल्दी खोजें

### macOS Tahoe में खोई हुई चीज़ें
- ❌ कस्टम ऐप संगठन
- ❌ यूज़र द्वारा बनाए गए फोल्डर
- ❌ ड्रैग-एंड-ड्रॉप कस्टमाइज़ेशन
- ❌ विज़ुअल ऐप मैनेजमेंट
- ❌ अनिवार्य श्रेणीबद्ध समूह

## विशेषताएँ

### 🎯 **तुरंत ऐप लॉन्च**
- डबल-क्लिक से सीधे लॉन्च

- रियल-टाइम फ़िल्टरिंग के साथ तेज़ खोज

- ऐप्स को ड्रैग करके फोल्डर बनाएं

- कस्टम फोल्डर आइकन और संगठन
- ऐप्स को अंदर/बाहर ड्रैग-एंड-ड्रॉप करें

### 🔍 **स्मार्ट सर्च**
- रियल-टाइम फ़ज़ी मैचिंग
- सभी इंस्टॉल्ड ऐप्स में खोज
- त्वरित पहुँच के लिए कीबोर्ड शॉर्टकट

### 🎨 **आधुनिक UI डिज़ाइन**
- **लिक्विड ग्लास इफ़ेक्ट**: regularMaterial + एलीगेंट शैडोज़
- फुल-स्क्रीन और विंडो मोड
- स्मूथ एनीमेशन और ट्रांज़िशन
- साफ़ और रेस्पॉन्सिव लेआउट

### 🔄 **सीमलेस डेटा माइग्रेशन**
- **वन-क्लिक Launchpad आयात** (macOS नेटिव DB से)
- ऐप्स का ऑटो-डिटेक्शन और स्कैन
- SwiftData के साथ लेआउट स्थाई भंडारण
- सिस्टम अपडेट के दौरान डेटा लॉस नहीं

### ⚙️ **सिस्टम इंटेग्रेशन**
- नेटिव macOS ऐप
- मल्टी-डिस्प्ले स्मार्ट पोजिशनिंग
- Dock और अन्य सिस्टम ऐप्स के साथ काम करता है
- बैकग्राउंड क्लिक डिटेक्शन (स्मार्ट क्लोज)

## तकनीकी संरचना

### आधुनिक तकनीक से निर्मित
- **SwiftUI**: डिक्लेरेटिव, हाई-परफॉर्मेंस UI फ्रेमवर्क
- **SwiftData**: शक्तिशाली डेटा परसीस्टेंस लेयर
- **AppKit**: macOS के साथ गहरा इंटेग्रेशन
- **SQLite3**: Launchpad DB का डायरेक्ट रीड

### डेटा स्टोरेज
ऐप डेटा सुरक्षित रूप से यहाँ संग्रहीत होता है:
```
~/Library/Application Support/LaunchOne/Data.store
```

### नेटिव Launchpad इंटेग्रेशन
सिस्टम Launchpad DB से सीधे पढ़ें:
```bash
/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db
```

## इंस्टॉलेशन

### सिस्टम आवश्यकताएँ
- macOS 26 (Tahoe) या उससे ऊपर
- Apple Silicon या Intel प्रोसेसर
- Xcode 26 (सोर्स से बिल्ड)

### सोर्स से बिल्ड

1. **रिपोजिटरी क्लोन करें**
   ```bash
   clone git@github.com:mamahuhu-io/LaunchOne.git
   cd LaunchOne
   ```

2. **Xcode में खोलें**
   ```bash
   open LaunchOne.xcodeproj
   ```

3. **बिल्ड और रन करें**
   - टारगेट डिवाइस चुनें
   - `⌘+R` से बिल्ड और रन
   - या `⌘+B` से केवल बिल्ड

### कमांड लाइन बिल्ड
```bash
xcodebuild -project LaunchOne.xcodeproj -scheme LaunchOne -configuration Release
```

## उपयोग

### त्वरित शुरुआत
1. **पहला लॉन्च**: LaunchOne इंस्टॉल्ड ऐप्स को ऑटो-स्कैन करता है
2. **चयन**: क्लिक करके चुनें, डबल-क्लिक से लॉन्च करें
3. **खोज**: टाइप करते ही तुरंत फ़िल्टरिंग
4. **व्यवस्थित करें**: ड्रैग करके फोल्डर/लेआउट बनाएं

### अपना Launchpad इम्पोर्ट करें
1. सेटिंग्स (गियर आइकन) खोलें
2. **"Import Launchpad"** पर क्लिक करें
3. आपकी मौजूदा लेआउट और फोल्डर स्वतः इम्पोर्ट हो जाएंगे

### फोल्डर मैनेजमेंट
- **फोल्डर बनाएँ**: एक ऐप को दूसरे पर ड्रैग करें
- **नाम बदलें**: नाम पर क्लिक करें
- **ऐप जोड़ें**: ऐप को फोल्डर में ड्रैग करें
- **ऐप हटाएँ**: ऐप को फोल्डर से बाहर ड्रैग करें

### डिस्प्ले मोड
- **विंडो**: राउंडेड कॉर्नर के साथ फ्लोटिंग विंडो
- **फुल-स्क्रीन**: अधिकतम दृश्यता
- सेटिंग्स में मोड स्विच करें

## समस्या निवारण

### सामान्य समस्याएँ

**प्रश्न: ऐप शुरू नहीं हो रहा?**
उत्तर: macOS 26+ सुनिश्चित करें और सिस्टम अनुमतियाँ जांचें।

**प्रश्न: इम्पोर्ट बटन गायब है?**
उत्तर: जाँचें कि SettingsView.swift में इम्पोर्ट फ़ंक्शन शामिल है।

**प्रश्न: खोज काम नहीं कर रही?**
उत्तर: ऐप्स को फिर से स्कैन करें या सेटिंग्स में ऐप डेटा रीसेट करें।

**प्रश्न: प्रदर्शन समस्याएँ?**
उत्तर: आइकन कैश सेटिंग्स जाँचें और ऐप पुनः शुरू करें।

## क्यों LaunchOne?

### Apple के "Applications" इंटरफ़ेस से तुलना
| फ़ीचर | Applications (Tahoe) | LaunchOne |
|---------|---------------------|------------|
| कस्टम संगठन | ❌ | ✅ |
| यूज़र फोल्डर | ❌ | ✅ |
| ड्रैग-एंड-ड्रॉप | ❌ | ✅ |
| विज़ुअल मैनेजमेंट | ❌ | ✅ |
| मौजूदा डेटा आयात | ❌ | ✅ |
| प्रदर्शन | धीमा | तेज़ |

### अन्य Launchpad विकल्पों से तुलना
- **नेटिव इंटेग्रेशन**: Launchpad DB सीधे पढ़ना
- **आधुनिक आर्किटेक्चर**: SwiftUI/SwiftData
- **शून्य निर्भरता**: प्योर Swift, कोई बाहरी लाइब्रेरी नहीं
- **सक्रिय विकास**: नियमित अपडेट
- **लिक्विड ग्लास डिज़ाइन**: प्रीमियम विज़ुअल इफेक्ट्स
