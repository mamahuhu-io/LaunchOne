macOS Tahoe убрал Launchpad, новый интерфейс неудобен и не использует в полной мере ваш Bio GPU. Apple, дайте хотя бы возможность вернуться к прежнему виду. А пока — LaunchOne.

*Основано на [LaunchNext](https://github.com/RoversX/LaunchNext) от RoversX — огромная благодарность оригинальному проекту!*

*LaunchNext использует лицензию GPL 3, LaunchOne следует тем же условиям.*

### Что предлагает LaunchOne
- ✅ **Импорт в один клик из старого системного Launchpad** — напрямую читает вашу нативную базу SQLite Launchpad (`/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db`) и воссоздаёт существующие папки, позиции приложений и раскладку
- ✅ **Классический опыт Launchpad** — работает так же, как любимый оригинал
- ✅ **Многоязычная поддержка** — полная интернационализация (английский, китайский, японский, французский, испанский)
- ✅ **Скрытие подписей значков** — минималистичный вид, когда названия не нужны
- ✅ **Настраиваемые размеры значков** — подстройка под предпочтения
- ✅ **Умное управление папками** — создание и организация, как раньше
- ✅ **Мгновенный поиск и навигация с клавиатуры** — быстрый доступ к приложениям

### Что мы потеряли в macOS Tahoe
- ❌ Нет кастомной организации приложений
- ❌ Нет пользовательских папок
- ❌ Нет drag-and-drop кастомизации
- ❌ Нет визуального управления приложениями
- ❌ Принудительная группировка по категориям

## Техническая архитектура

### Построено на современных технологиях
- **SwiftUI** — декларативный UI-фреймворк
- **SwiftData** — мощная персистентность данных
- **AppKit** — глубокая интеграция с macOS
- **SQLite3** — прямое чтение базы Launchpad

### Хранилище данных
Данные приложения сохраняются по адресу:
```
~/Library/Application Support/LaunchOne/Data.store
```

### Нативная интеграция Launchpad
Прямое чтение из системной базы:
```bash
/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db
```

## Установка

### Требования
- macOS 26 (Tahoe) и выше
- Apple Silicon или Intel
- Xcode 26 (для сборки из исходников)

### Сборка из исходников

1. **Клонировать репозиторий**
   ```bash
   clone git@github.com:mamahuhu-io/LaunchOne.git
   cd LaunchOne
   ```

2. **Открыть в Xcode**
   ```bash
   open LaunchOne.xcodeproj
   ```

3. **Собрать и запустить**
   - Выберите целевое устройство
   - Нажмите `⌘+R` для сборки и запуска
   - Или `⌘+B` для сборки

### Сборка из командной строки
```bash
xcodebuild -project LaunchOne.xcodeproj -scheme LaunchOne -configuration Release
```

## Использование

### Быстрый старт
1. **Первый запуск**: LaunchOne автоматически сканирует установленные приложения
2. **Выбор**: Клик для выбора, двойной клик для запуска
3. **Поиск**: Печатайте для мгновенной фильтрации
4. **Организация**: Перетаскивайте приложения для создания папок и раскладки

### Импорт вашего Launchpad
1. Откройте настройки (значок шестерёнки)
2. Нажмите **"Import Launchpad"**
3. Текущая раскладка и папки будут импортированы автоматически

### Управление папками
- **Создание папки**: Перетащите одно приложение на другое
- **Переименование**: Клик по названию
- **Добавить приложения**: Перетаскивайте в папку
- **Удалить приложения**: Перетаскивайте из папки

### Режимы отображения
- **Окно**: плавающее окно со скруглёнными углами
- **Полный экран**: максимальная видимость
- Переключайте режим в настройках

## Известные проблемы

> **Текущий статус разработки**
> - 🔄 **Прокрутка**: иногда нестабильна, особенно при быстрых жестах
> - 🎯 **Создание папок**: hit-test для drag-and-drop иногда непоследователен
> - 🛠️ **Активная разработка**: исправления в ближайших релизах

## Устранение неполадок

### Частые вопросы

**В: Приложение не запускается?**
О: Убедитесь, что у вас macOS 26+ и проверьте системные разрешения.

**В: Кнопка импорта отсутствует?**
О: Проверьте, что в SettingsView.swift есть функция импорта.

**В: Поиск не работает?**
О: Повторно просканируйте приложения или сбросьте данные в настройках.

**В: Проблемы с производительностью?**
О: Проверьте настройки кэша иконок и перезапустите приложение.

Пока Apple отходит от настраиваемых интерфейсов, LaunchOne — это заявление сообщества в пользу пользовательского контроля и персонализации. Мы верим, что пользователи должны сами решать, как организовывать рабочее пространство.
